# Progress event fixtures

`valid/` streams are generated by `fusion simulate` from the example
tasks and are asserted byte-for-byte in `tests/progress.test.ts`. `invalid/`
streams are hand-mutated copies that each trigger one validator violation.

Every fixture has `origin: "dry-run-simulation"`. Timestamps start at
2000-01-01T00:00:00Z and advance one second per event. They are synthetic and
carry no information about real execution.

| Fixture | Scenario | Final states |
| --- | --- | --- |
| `valid/nominal-critique.json` | all legs succeed | leg-0..2 `succeeded` |
| `valid/cancelled-at-leg-0.json` | cascade, cancel while leg 0 runs | leg-0 `cancelled`, leg-1 `cancelled` |
| `valid/timed-out-at-critic.json` | critique, critic times out | leg-0 `succeeded`, leg-1 `timed-out`, leg-2 `cancelled` |
| `valid/budget-exhausted-at-leg-0.json` | single, budget stop | leg-0 `budget-exhausted` |

| Invalid fixture | Violation code |
| --- | --- |
| `duplicate-sequence.json` | `sequence-not-contiguous` |
| `out-of-order-sequence.json` | `sequence-not-contiguous` and cascading transition errors |
| `planned-to-running.json` | `invalid-transition` |
| `event-after-terminal.json` | `event-after-terminal` |
| `first-state-not-planned.json` | `first-state-not-planned` |
| `timestamp-regresses.json` | `timestamp-not-monotonic` |
| `workflow-id-mismatch.json` | `workflow-id-mismatch` |
| `origin-mismatch.json` | `origin-mismatch` |
| `malformed-schema.json` | `schema` |

Regenerate the valid set with:

```bash
npm run dev -- simulate examples/tasks/medium-risk-cascade.json --scenario cancelled --at 0 > fixtures/progress/valid/cancelled-at-leg-0.json
npm run dev -- simulate examples/tasks/high-risk-critique.json --scenario timed-out --at 1 > fixtures/progress/valid/timed-out-at-critic.json
npm run dev -- simulate examples/tasks/low-risk-single.json --scenario budget-exhausted --at 0 > fixtures/progress/valid/budget-exhausted-at-leg-0.json
npm run dev -- simulate examples/tasks/high-risk-critique.json --scenario nominal > fixtures/progress/valid/nominal-critique.json
```
